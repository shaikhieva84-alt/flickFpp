# 🎬 FlickApp

**FlickApp** — мобильное приложение для поиска фильмов и сериалов, созданное на **Flutter**. Приложение позволяет просматривать информацию о фильмах, искать новинки, добавлять их в избранное и получать современный пользовательский опыт.

## 🚀 Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/FlickApp.git
```

### 2. Перейти в папку проекта

```bash
cd FlickApp
```

### 3. Установить зависимости

```bash
flutter pub get
```

### 4. Создать файл `.env`

```env
API_KEY=YOUR_API_KEY
```

### 5. Запустить проект

```bash
flutter run
```
